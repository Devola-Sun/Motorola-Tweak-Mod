## What's Changed in v2.5.5

This release brings Liquid Glass styling to key areas across the launcher and SystemUI, adds in-app update checks, and improves reliability across settings, hooks, and device-specific layouts.

### ✨ Liquid Glass
- **Notification Center:** Added glass styling for notification and media surfaces, including expanded media artwork.
- **Control Center:** Added refined glass surfaces and blur handling for Quick Settings.
- **Lock Screen:** Added optional glass styling for lock-screen shortcuts and playback cards, with compact media controls and improved notification layout behavior.
- **Desktop:** Added glass effects for launcher surfaces, including folders and the main dock.

### 🔔 Update Checks
- Added optional in-app checks for new stable GitHub releases, with a direct link to the release page.
- Added version-aware release comparison and safeguards against repeated or unnecessary checks.

### 🛠️ Stability and Improvements
- Improved hook resilience and settings synchronization across the launcher and SystemUI.
- Refined control-center layouts, lock-screen media handling, notification behavior, and launcher grid options.
- Improved root command handling and scope detection.

### 📦 Installation & Updating
1. Install the updated APK over your existing version.
2. Ensure the module retains the required LSPosed and root permissions.
3. Reboot or restart SystemUI/Launcher as prompted for the updated hooks to take effect.

Some SystemUI and launcher effects depend on the device ROM and should be verified on-device. Options remain configurable in the app; disable an affected option and restart the corresponding process if needed.
